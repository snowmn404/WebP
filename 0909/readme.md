**파인만 공부법**
1단계 (개념 고르기): 공부하고 싶은 주제나 개념을 정하고 종이 상단에 적습니다.
2단계 (쉽게 설명하기): 배운 내용을 배경지식이 없는 사람이나 아이에게 가르치듯 소리 내어 쉽게 설명합니다.
3단계 (막힌 곳 되돌아가기): 설명하다가 막히거나 어려운 용어로 얼버무리는 지점을 찾고, 교재를 다시 보며 보완합니다.
4단계 (비유로 단순화하기): 복잡한 표현을 일상적인 비유나 단순한 언어로 다듬어 완전히 내 것으로 만듭니다.

**HTML Block and lnline Elements**
블록 레벨 요소는 항상 새 줄에서 시작하며, 브라우저는 요소 앞뒤로 자동으로 약간의 여백(마진)을 추가합니다.
블록 레벨 요소는 항상 사용 가능한 전체 너비를 차지하며, 왼쪽과 오른쪽으로 최대한 늘어납니다.
자주 사용되는 두 가지 블록 요소는 <p>와 <div>입니다.
<p> 요소는 HTML 문서에서 문단을 정의합니다.
<div> 요소는 HTML 문서에서 구역이나 섹션을 정의합니다.
